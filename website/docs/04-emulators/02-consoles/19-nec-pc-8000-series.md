# NEC - PC-8000 & PC-8800 series ⚠

- Emulator: quasi88
- Rom Folder: `PCEIGHTYEIGHT`
- Extensions: `.d88` `.u88` `.m3u`  
  (disk images must be uncompressed: the core opens the image file directly, so a `.zip` only boots to the BASIC screen)
- Bios: Optional. The core has a built-in fallback BIOS. Real dumps (`n88.rom`, `n88_0.rom` ... `n88_3.rom`, `n88n.rom`, `disk.rom`, `n88knj1.rom`, `n88knj2.rom`, `n88jisho.rom`) need to be placed in a folder named `quasi88` within the `BIOS` folder
